# Kvelibot

Telegram-бот для автоматической сортировки списков развоза и распределения адресов по районам и времени.

## Описание

Kvelibot принимает на вход неотсортированный список с именами и адресами, анализирует каждую строку и возвращает готовый список, сгруппированный по времени закрытия и районам.

Бот умеет определять:
- район по адресу (СЗР, ЮЗР, Центр, Новый, НЧК, НЮР, Кугеси, Богданка и др.)
- часы доставки/закрытия (например, до 22:00, до 23:00, до 01:00)
- роль/секцию, если она указана в списке
- нераспознанные адреса и добавляет их в секцию `НЕОПРЕДЕЛЕНО`

## Функционал

- Обработка текстовых списков, присланных пользователем
- Разбор строк с разными форматами: `Имя - Адрес`, `Имя Адрес`, `Адрес` и т.д.
- Нормализация адресов и поиск района через словари синонимов
- Автоматическая группировка по:
  - времени (`22:00`, `23:00`, `00:00`, `01:00`)
  - районам и водителям
- Специальная логика распределения:
  - `БОГДАНКА` распределяется между водителями, если есть
  - `СЗР` и `ЮЗР` идут первыми для первого водителя
  - `ЦЕНТР`, `НОВЫЙ`, `НЧК` для второго водителя
  - `НЮР`, `КУГЕСИ` для третьего водителя
- Команды бота:
  - `/start` — приветственное сообщение и текущие времена
  - `/help` — подробная инструкция
  - `/times` — текущие раннее и основное времена закрытия

## Структура проекта

- `bot.py` — основной модуль бота Telegram на Aiogram
- `processor.py` — логика разбора и сортировки списка
- `address_data.py` — база районов, адресов и синонимов
- `requirements.txt` — зависимости проекта
- `logo/logo.png` — логотип проекта

## Установка

1. Создайте виртуальное окружение:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
2. Установите зависимости:
   ```powershell
   pip install -r requirements.txt
   ```

## Переменные окружения

Создайте файл `.env` в корне проекта с переменными:

```text
BOT_TOKEN=ваш_токен_бота
HTTPS_PROXY=адрес_прокси_если_нужен
```

Если прокси не требуется, можно убрать переменную `HTTPS_PROXY` или не использовать `AiohttpSession` с прокси.

## Запуск

```powershell
python bot.py
```

## Пример использования

1. Отправьте боту НЕотсортированный список с адресами и именами.
2. Бот вернёт итоговый отсортированный список с разделением по времени и районам.
3. Нераспознанные адреса будут вынесены в секцию `НЕОПРЕДЕЛЕНО`.
